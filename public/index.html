Sobre o MonIC

O MonIC é um sistema de gerenciamento de monitorias desenvolvido para o Instituto de Computação da UFAL.

Funcionalidades principais:

  • Agendamento de monitorias
  • Gerenciamento de materiais didáticos
  • Sistema de avisos e comunicados
  • Acompanhamento de participação

Créditos: Sistema desenvolvido como projeto acadêmico para modernização dos processos de monitoria do IC/UFAL.
